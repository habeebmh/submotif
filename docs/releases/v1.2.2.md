Submotif is a free, open-source MIDI bassline generator. This first public release includes VST3 and Max for Live editions with Deep House, Rolling, Offbeat, Acid, Disco and Funk styles.

Each Generate builds a fresh phrase using weighted rhythmic choices, harmonic roles and motif development. Start in C minor at C1 with one bar; adjust the style, key and length, lock notes, or change a few notes while keeping the phrase.

### Downloads

- **Mac, recommended:** `Submotif-macos-universal.zip` — Apple Silicon and Intel, macOS 11+.
- **Smaller Mac builds:** `Submotif-macos-arm64.zip` or `Submotif-macos-x86_64.zip`.
- **Windows:** `Submotif-windows-x64.zip` — Windows 10/11, x64.

Every ZIP includes the Max for Live device, an optional standalone MIDI inspection app, matching source, complete pinned JUCE source, license notices and file checksums. Adjacent `.sha256` files verify the ZIP downloads; `.json` files record the exact tag, source commit and build target.

### Installation

Extract the ZIP. Copy the complete VST3 bundle into `~/Library/Audio/Plug-Ins/VST3/` on Mac or `C:\Program Files\Common Files\VST3\` on Windows, then rescan your DAW. Read the included `INSTALL.md` or the [installation guide](https://github.com/habeebmh/submotif/blob/v1.2.2/docs/INSTALL.md).

For **one Ableton track**, keep the `max/` folder together and place **Submotif.amxd before Serum or your other instrument**. Requires Max for Live and Max 9.1.3+. The VST3 edition uses two routed MIDI tracks in Ableton. Submotif supplies MIDI, not audio; no Serum preset or synth is included.

### Signing and testing

**Mac downloads are ad-hoc signed, not Developer ID signed or notarized. Windows downloads are unsigned.** Operating systems and hosts may warn or block loading. These are manual-install ZIPs, not signed installers.

All four target builds run native tests, 38 Max checks, a 1,260-pattern C++/Max parity comparison and composition audit checks. Mac builds also exercise the actual VST3 wrapper; Windows currently has engine, processor and editor tests. Broader DAW testing and listening feedback remain welcome; automated checks do not prove musical quality or universal host compatibility. See the [validation record](https://github.com/habeebmh/submotif/blob/v1.2.2/docs/VALIDATION.md).
