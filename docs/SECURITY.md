# Security policy

SUBMOTIF is an early-stage project. Security fixes will target the latest published version and the current development branch; there is no separate long-term support commitment for older versions. The source repository is public; no packaged release is available yet.

## Report a vulnerability privately

Use [GitHub's private vulnerability reporting](https://github.com/habeebmh/submotif/security/advisories/new), which is enabled for this repository. If that option is unavailable, open a minimal [issue](https://github.com/habeebmh/submotif/issues) requesting a private reporting channel **without disclosing the vulnerability or exploit**.

Include the affected version, operating system, host, a clear description of the impact, and minimal reproduction steps. Share a proof of concept privately if one is needed. Remove credentials, private music, personal paths, and other sensitive information from attachments.

Please allow time to investigate and coordinate a fix before publishing exploit details. Reports are reviewed by the maintainer, but response times and rewards are not guaranteed. This is not a paid bug bounty program.

For ordinary crashes, MIDI routing problems, or incorrect generation, use the public issue tracker unless the report reveals a security vulnerability.
